HOW TO UPLOAD TO GITHUB (repo: the-bloomelle-house, branch: main)

1. index.html  -> replace the existing index.html in the repo root
2. favicon.ico, favicon-16x16.png, favicon-32x32.png, favicon-48x48.png,
   apple-touch-icon.png, icon-192.png, icon-512.png  -> repo root (next to index.html)
3. assets/svc-*.jpg and assets/review-photo.jpg  -> the existing assets folder
   (keep your current logo.png, hero.mp4, before/after images as they are)

Then hard-refresh the site (Ctrl+Shift+R). Favicons are cached, so use a private window to check.
